EnderIO is a fully featured tech mod, with armor, weapons, tools, machines, conduit, inventory management and mobs.

The post-1.12.2 version of the mod has been rewritten from the ground up, so we are still working on implementing everything you know and love from the original version of EnderIO. Look in the sidebar to see what we have so far. If you aren't sure where to begin, start with <ItemLink id="enderio:grains_of_infinity" />.
